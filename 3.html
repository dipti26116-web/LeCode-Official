Simple HTML5 Learn

HTML5 is the latest version of HTML and it introduces many new features and improvements over the previous versions. In this tutorial, we will learn the basics of HTML5 and how to use it to create web pages.

What is HTML5?

HTML5 is a markup language used to create web pages and web applications. It is the latest version of HTML and it introduces many new features and improvements over the previous versions. HTML5 is designed to be more semantic and easier to use than previous versions of HTML.

How to code HTML5

First we need to let the browser know this is a brand new HTML5 Document/File <!DOCTYPE html> Then we have to start our code using this command: <html> After that is done, we would want some text to appear on our browser dashboard/homepage, in this case, we do: <body< The text you would want to write here </body> Finally, we close our HTML5 Document/File with this command: </html> This code prints whatever you wrote in between the body commands, in my case, it would print "The text you would want to write here" You must have noticed that when we wanted to close body and html, we used a /, well yes, in HTML5 or whatever HTML version you are using, You always close the commands like body or html using a /.
