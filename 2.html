Lists in python

Lists are used to store multiple items in a single variable.

Lists are one of 4 built-in data types in Python used to store collections of data, the other 3 are Tuple, Set, and Dictionary, all with different qualities and usage.

Lists are created by placing all the items (elements) inside square brackets [], separated by commas, and can be assigned to a variable.

Lists are mutable, meaning, value of elements of a list can be altered.

Lists are written with square brackets.

Examples: fruits = ["apple", "banana", "grapes"] print(fruits) This prints: 'apple', 'banana', 'grapes' If you want to print a single word form the lists: Python knows words inside lists as numerals: [0], [1], [2] and so on If you want to use these in a python code then you can just: fruits = ["apple", "banana", "grapes"] print(fruits[0]) In this case, [0] is known as: apple, if you want to print banana, just turn [0] into [1], and if you want to print grapes, just turn your [0] or [1] to [2] If you want to add something new to your lists just use "append" fruits = ["apple", "banana", "grapes"] fruits.append("orange") print(fruits) This prints: 'apple', 'banana', 'grapes', 'orange' If you want to remove something from your lists just use "remove" fruits = ["apple", "banana", "grapes"] fruits.remove("apple") print(fruits) This prints: 'banana', 'grapes' There are many more things you can do with lists, but I will leave it at that for now More lists code comning soon!
