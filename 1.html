HOW DOES THREE.JS WORK?

Three.js is a Javascript library that renders 3D objects, it is used for making 3D web games, many web games like Slow Road, Off Road Earth etc use Three.js. Not only games but many webs that help us to import models, webs to download 3d games also use Three.js. Three.js mainly uses WebGL, which is a javascript API for rendering 3D graphics in the browser, usually imported through importmap, in html. It also uses javascript features for certain things and does not cut off javascript forever like:

Const Let Arrow functions Classes Template literals Object destructuring Array destructuring Spread operator Rest operator Async/await Generators Modules To import a renderer we do: const renderer = new THREE.WebGLRenderer (import THREE from "three"; is required) Then we add it to the body of the html: document.body.appendChild(renderer.domElement); Then we create a scene: const scene = new THREE.Scene(); Then we create a camera: const camera = new THREE.PerspectiveCamera(75, window.innerWidth/window.innerHeight, 0.1, 1000); Then we create a cube: const geometry = new THREE.BoxGeometry(); const material = new THREE.MeshBasicMaterial({color: 0x00ff00}); const cube = new THREE.Mesh(geometry, material); Then we add the cube to the scene: scene.add(cube); Then we move the camera back: camera.position.z = 5; Then we create a render loop: function animate() { requestAnimationFrame(animate); cube.rotation.x += 0.01; cube.rotation.y += 0.01; renderer.render(scene, camera); } animate(); And that's it! We've created a basic 3D scene with a rotating cube.
